This blog collects longer-form notes on AI agents, software engineering, developer tools, and building real systems.

## How claims are labeled

Analysis articles here label their important claims so you can tell sourced facts from my opinions:

- <span class="label documented">Documented</span>: stated in official documentation or source material, linked next to the claim.
- <span class="label verified">Verified</span>: checked directly in source code or with an experiment described well enough to rerun.
- <span class="label observed">Observed</span>: something I noticed in use, not a controlled test.
- <span class="label opinion">Opinion</span>: my interpretation.
- <span class="label proposal">Proposal</span>: an idea or setup you should evaluate for yourself.

Tools change quickly, so articles also state the versions and dates they were checked against. If something is out of date or wrong, please let me know.
